# PandaUI 2.2.1

Tower Shift s uloženou partií, skiny a bonusy. Osobní přehled se otevírá podržením loga 3 sekundy a zadáním PINu. Při prvním použití bez původního PINu se PIN nastaví. Zámek v horní liště vrací do hry. Záznamy nejsou šifrované.

Obsahuje kalendář historie, vlastní rozložení widgetů, nákupní statistiky a opravu dvojího zápisu po rozšířeném uložení dávky. Původní klíče dat i adresa zůstávají zachované.

Produkční soubory: index.html, sw.js, manifest.webmanifest, icon.svg, icon-180.png, icon-192.png, icon-512.png, assets/app.css, assets/widgets.css, assets/ios.css, assets/library.css, assets/cover.css, assets/core.js, assets/library.js, assets/cover.js, assets/widgets.js, assets/stack-mark.svg. Náhledy, zálohy a preview-data.js nejsou součástí vydání.
